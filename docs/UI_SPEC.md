# 界面规范（UI Spec）

设计稿：`docs/design/` 下的 4 个静态 HTML（用浏览器打开 `docs/design/index.html` 可并排查看）。
设计稿画布为 **1280×800，1px = 1dp**，对应小米平板横屏。实现时以 dp 为单位照搬尺寸。

> 风格关键词：**纯白 / 纯黑底 + 鲜艳多彩点缀**，干净、像 Apple 一样克制；**不用毛玻璃（blur）**，播放页沉浸式。

---

## 1. 主题

App 有浅色、深色两套主题，默认**跟随系统**，设置里可手动切换（跟随系统 / 浅色 / 深色）。
**播放页永远是深色**，与主题无关。

### 1.1 中性色

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `background` | `#FFFFFF` | `#0B0C0F` | 页面底色（浅色必须纯白） |
| `surface` | `#F6F7F9` | `#16181D` | 大卡片（输入卡、解析结果卡） |
| `surfaceItem` | `#FFFFFF` | `#1E2026` | 卡片里的行（文件行） |
| `outline` | `#ECEEF2` | `#1C1F25` | 侧栏分隔线、进度条底轨 |
| `divider` | `#E6E8ED` | `#24272E` | 卡片内分隔线 |
| `onBackground` | `#14161B` | `#F2F3F5` | 主文字 |
| `onSurfaceVariant` | `#5F6571` | `#9AA0AB` | 次要文字（满足 4.5:1 对比度） |

### 1.2 彩色（多彩点缀）

每种颜色有三种用法：**实色**（图标块、封面、实心按钮）、**浅底**（tint 背景）、**浅底上的文字色**。

| 颜色 | 浅色 · 实色 | 浅色 · 浅底 / 文字 | 深色 · 实色 | 深色 · 浅底 / 文字 |
|---|---|---|---|---|
| 蓝 Blue（主色） | `#2F6BFF` | `#EAF0FF` / `#1D4FD8` | `#2F6BFF`（按钮）、`#6E9BFF`（图标） | `rgba(76,130,255,.16)` / `#8FB0FF` |
| 粉 Pink | `#FF3D7F` | `#FFE8F0` / `#C2185B` | `#E6407F`（填充）、`#FF5C99`（图标） | `rgba(255,92,153,.16)` / `#FF8FB8` |
| 绿 Green | `#12B886` | `#E3F7EF` / `#0B7A55` | `#13A877`（填充）、`#2BD49A`（图标）、`#20B985`（开关） | `rgba(43,212,154,.14)` / `#6FE3B9` |
| 紫 Purple | `#7C5CFF` | `#EFEBFF` / `#5B3FD9` | `#7158F0`（填充）、`#A592FF`（图标） | `rgba(155,133,255,.16)` / `#BBAEFF` |
| 橙 Orange | `#FF8A00` | `#FFF1E0` / `#B35A00` | `#FFA23A`（填充，上面用深色字 `#2A1500`） | `rgba(255,162,58,.16)` / `#FFC27A` |

**主操作**（解析并播放、播放按钮、进度条已播放部分）一律用蓝色 `#2F6BFF` + 白字，两种主题相同。

### 1.3 颜色语义（保持一致）

| 区域 / 功能 | 颜色 |
|---|---|
| 首页、主操作、播放 | 蓝 |
| 最近播放 | 粉 |
| 缓存、粘贴、开关、下载速度、"可以播放"状态 | 绿 |
| 设置、节点数、画质、文件大小 | 紫 |
| 字幕文件、种子文件按钮、提示条、倍速 | 橙 |
| 播放页的字幕按钮 | 粉 |
| 最近播放封面、文件列表图标 | 按顺序轮换 粉 → 绿 → 紫 → 蓝 → 橙 |

## 2. 字体与尺寸

- 字体：**系统默认字体**（小米上是 MiSans），不内置字体文件。数字用等宽数字（`fontFeatureSettings = "tnum"`）。
- 字号（sp）：页面标题 32 / 700；卡片标题 18 / 700；种子名 17 / 700；列表主文字 14–15 / 600；次要文字 12–13 / 400–500；字幕中文 26 / 600，原文 17。
- 圆角（dp）：大卡片 24；行、封面、大按钮 16；普通按钮 14；图标块 12；标签 8；胶囊 999。
- 间距：4dp 栅格。卡片内边距 22，页面内边距 36–40，模块间距 24–28。
- 所有可点击区域 **≥ 44dp**。

## 3. 页面

### 3.1 首页（`docs/design/home-light.html`、`home-dark.html`）

横屏两栏，左侧一条 88dp 窄导航栏：

- **导航栏**：顶部黑色（深色主题为白色）圆角方块 Logo；下面是首页（蓝，选中时浅蓝底）、最近（粉）、缓存（绿）；底部设置（紫）。每个图标用自己的颜色。
- **左栏（约 55%）**
  1. 小标题"边下边播 · 原画 · 不留文件" + 大标题"粘贴磁力链接，马上开播"。
  2. **输入卡**（`surface` 底）：磁力链接输入框（白底，1.5dp 蓝色描边，左侧蓝色链接图标）；按钮行：`粘贴`（绿色浅底）、`种子文件`（橙色浅底，打开系统文件选择器选 .torrent）、`解析并播放`（蓝色实心，占满剩余宽度）。
     - 启动 App 或回到前台时，若剪贴板里有 `magnet:` 链接，自动填入并提示。
  3. **最近播放**：一行 3 张卡片，彩色实色封面（无截图时）+ 白色圆形播放图标，标题、彩色进度条（颜色与封面一致）、"看到 42:10 · 剩 1:15:50"。点击从上次位置继续播放。"全部"进入最近列表页。
  4. **提示条**（橙色浅底）：拖动进度条会优先下载对应位置。可关闭，关闭后不再显示。
- **右栏（约 45%）解析结果卡**
  - 标题"解析结果" + 状态胶囊（绿色"可以播放" / 灰色"正在获取元数据…" / 红色"解析失败"）。
  - 种子名 + 三个彩色标签：文件数（蓝）、总大小（紫）、节点数（粉）。
  - 文件列表：视频文件在前、按文件名排序；每行彩色图标块、文件名、`大小 · 编码 · 分辨率`、右侧圆形播放按钮（第一个视频为蓝色实心，其余为浅底）。字幕文件显示"字幕"标签，不可播放，播放时自动加载。其他无关文件（图片、txt 等）默认折叠。
  - 底部设置：`看完自动清空缓存`（开关，默认开）、`缓存上限`（默认 300 MB，可选 100 / 200 / 300 / 500 / 1000 MB）。
  - 底部大按钮"播放 <第一个视频>"。
- 未解析时，右栏显示空状态（插画位 + "粘贴链接后，这里会列出可以播放的文件"）。

### 3.2 播放页 · 控件显示（`docs/design/player-controls.html`）

- **沉浸式全屏**：隐藏状态栏和导航栏，视频铺满。**不使用任何毛玻璃 / blur。**
- 控件浮在画面上，只靠渐变暗角保证可读：顶部 160dp 从 `rgba(0,0,0,.7)` 到透明；底部 260dp 从透明到 `rgba(0,0,0,.8)`。
- 轻点画面显示 / 隐藏控件，3 秒无操作自动隐藏（暂停时不隐藏）。
- **顶栏**：返回、标题 + `分辨率 · 编码 · 大小`；右侧实时状态：下载速度（绿 `#3DE0A6`）、节点数（紫 `#B6A6FF`）、缓冲 `已缓存 / 上限`（橙 `#FFC27A`）；字幕按钮（粉 `#FF6FA3`）、更多菜单（竖三点：音轨、画面比例、解码方式、种子信息）。
- **中间**：后退 10 秒（64dp，`rgba(0,0,0,.35)` 圆底）、播放 / 暂停（88dp，蓝色实心）、前进 10 秒（64dp）。
- **字幕**：底部居中，双语时上行原文 17sp（85% 白）、下行中文 26sp / 600，带黑色阴影。
- **进度条**（左右边距 40dp）：5dp 高，底轨 `rgba(255,255,255,.2)`；**已下载片段**用 `rgba(255,255,255,.45)` 分段显示（BT 特色，可能不连续）；已播放部分蓝色；拖动点 18dp 白色 + 4dp 蓝色外环。
  - 已下载片段的数据：优先用 TorrServer 的缓存 / 分片信息；拿不到时退回 mpv 的 `demuxer-cache-state` 里的 `seekable-ranges`。
  - 拖动时在拖动点上方显示预览小卡：目标时间 + 状态（"已下载 · 秒开" 绿色 / "需要下载" 灰色）。
- **底栏**：`42:10 / 1:58:00`、图例（已播放 / 已下载片段）；右侧彩色实心胶囊按钮：`字幕 中/日`（粉）、`1.0×`（橙，深色字）、`原画 2160p`（紫）；锁定屏幕、画中画图标按钮。
- **手势**：左右双击 ±10 秒；横向滑动拖进度；左侧上下滑调亮度，右侧上下滑调音量；长按 2 倍速（松手恢复）。
- 缓冲中：中间显示圆形加载指示 + 当前下载速度。

### 3.3 播放页 · 字幕面板（`docs/design/player-subtitles.html`）

- 点字幕按钮，从右侧滑出 **380dp 实色面板**（`#121318`，左侧 1dp 分隔线 `#1E2026`），视频区域加 35% 黑色遮罩但**继续播放**。
- 内容从上到下：
  1. 标题"字幕" + 关闭按钮。
  2. **可用字幕**：种子内字幕、已加载的外部字幕（选中项粉色 1.5dp 描边 + 浅粉底 + 对勾）；`关闭字幕`。
  3. **获取更多**：`在线搜索字幕`（蓝，伪射手 · 迅雷）、`AI 识别并翻译`（紫，标"第二期"，第一期置灰不可点）、`从平板选择字幕文件`（绿，SRT · ASS · VTT）。
  4. 底部设置：`双语显示`（开关）、`字号`（小 / 标准 / 大 分段，选中项橙色）、`字幕时间偏移`（− / + 每次 0.5 秒）。

---

## 4. 动效

- 页面切换：淡入 + 轻微上移（200ms）。
- 控件显示 / 隐藏：淡入淡出 150ms。
- 字幕面板：从右滑入 250ms（`FastOutSlowIn`）。
- 不做花哨动画，保持安静。
